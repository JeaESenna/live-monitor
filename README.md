# 直播监测

实时监测主播开播情况的 Windows 桌面软件。打开软件后自动在后台定时检测你添加的直播间，主播一开播立即弹出置顶小窗 + 提示音，一键打开网页版直播间。

## 特点

- **自定义直播间**：支持 斗鱼 / 虎牙 / B站 / 抖音 / 快手，粘贴直播间链接或直接输入房间号即可添加
- **自动监测**：启动即开始后台轮询（默认每 30 秒），无需任何手动操作；网络波动时保持上次已知状态，不会误报
- **开播提醒**：检测到开播 → 右下角弹出置顶提醒小窗（**不抢占焦点**，不打断游戏/工作）+ 提示音。窗口**常驻显示直到你手动操作**，弹窗未关时提示音默认每 60 秒温和重复一次
  - 「打开直播间」一键直达网页版
  - 「忽略」关闭本次弹窗（下次开播仍会提醒）
  - 「不再提醒」本次开播不再提醒（主播下播后自动恢复）
- **状态记录**：每个直播间的状态、直播标题、最后检测时间、**上次开播时间**都会记录并保存，重启软件后自动恢复显示；直播中的房间整行绿色高亮，与未开播一眼区分
- **极致轻量**：原生 C# WinForms 程序，无任何第三方依赖，空闲 CPU ≈ 0%，内存约 30~40 MB，可最小化到托盘静默运行
- **简洁干净**：白底黑字田字格图标、扁平化浅色界面
- 关闭主窗口自动最小化到托盘继续监测

## 使用方法

1. 双击运行 `dist\直播监测.exe`（首次运行可能在窗口右下角被 SmartScreen 提示，点「更多信息 → 仍要运行」即可）
2. 点击右上角 **「+ 添加直播间」**，粘贴直播间链接或输入房间号 → 软件自动识别平台和主播 → 点「添加」
3. 完成。之后主播开播时自动弹窗提醒。建议点「设置」按需调整检测间隔（默认 30 秒）

> 配置文件 `config.json` 自动生成在程序同目录（无权限时位于 `%APPDATA%\LiveMonitor`），绿色便携，删除即恢复出厂。

| 平台 | 示例 |
| ---- | ---- |
| 斗鱼 | `https://www.douyu.com/9999` 或 `9999` |

### 托盘菜单

右键任务栏托盘图标：显示主界面 / 暂停监测 / 立即检测 / 退出。

### 设置项

- 检测间隔（15~3600 秒，默认 30）
- 提示音开关、**循环提示间隔**（默认 60 秒；弹窗显示期间每隔 N 秒重复一次，**关闭弹窗即停止**）、试听
- **自定义提示音**：支持选择 wav/mp3 音频文件（留空使用内置提示音），试听按钮预览当前选择
- **自动打开直播间**：勾选后，检测到开播先弹窗+提示音，3 秒后自动打开直播间网页并关闭弹窗（提前点击任意按钮则按你的操作执行）
- **弹窗自动关闭**（默认 0 = 常驻显示直到手动操作；设为 N 秒则自动关闭）
- 启动时对已在直播的房间是否也提醒
- 关闭主窗口时：最小化到托盘 / 直接退出

### 列表右键菜单

打开直播间 / 立即检测该房间 / **开/关该主播的开播提醒**（对应列表「提醒」列）/ 复制链接 / 删除。

## 状态图标含义

- 🟢 **直播中**（整行浅绿高亮；B站轮播显示「轮播中」）
- ⚪ 未开播
- 🟠 直播中(异常)/未开播(异常)：最近一次检测网络失败，显示上次已知状态，网络恢复后自动修正
- 🔴 房间不存在 / 检测失败
- 列表记录「最后检测」和「上次开播」时间——**上次开播优先取平台返回的真实开播时间**（如 B站直播页面的 live_time），重启软件后状态不丢失

## 技术说明

- 无第三方依赖：仅用 Windows 自带 .NET Framework 4.8 的 `csc.exe` 编译，任何 Win10/11 可直接运行
- **合规低风险检测**：B站优先读取公开直播间网页（与正常浏览器访问完全相同），接口仅作备用；单线程顺序轮询、默认 30 秒间隔（最短 15 秒）、请求前自动预热浏览器 Cookie，避免触发平台风控
- 单后台线程 + 事件等待轮询（等待期间零 CPU）；HTTP 连接复用；检测失败不影响其他房间
- 日志：`dist\logs\app.log`（超过 1MB 自动轮转），记录每次检测结果与状态切换
- 自诊断：`dist\LiveMonitorTest.exe` 离线运行 50+ 项解析/配置/资源自测，结果写入 `dist\selftest_result.txt`

## 常见问题

1. **状态显示「直播中(异常)」/「未开播(异常)」**：最近一次检测网络失败或平台限流，软件保持上次已知状态并显示橙色提示；连续 2 次检测失败才会切换为「检测失败」。网络恢复后自动修正
2. **为什么有时检测到开播不立刻弹窗**：连续 2 次确认机制与弹窗冷却时间（同一主播 3 分钟内只提醒一次）用于过滤平台接口抖动和主播反复上下播，避免误报轰炸
3. **抖音显示「接口受限」**：抖音风控较严，先手动用浏览器打开一次该直播间再重试；仍失败则先不添加（软件会持续重试）
4. **虎牙偶尔检测失败**：虎牙网页偶发反爬拦截，下一轮会自动恢复
5. **双击行 / 右键菜单**：打开网页直播间、立即检测该房间、开/关该主播的开播提醒、复制链接、删除
6. **排查问题**：每次检测结果和状态切换都记录在 `dist\logs\app.log`（UTF-8，用记事本打开），反馈问题时请附带此文件
7. **修改后如何重新打包**：`build\build.ps1` 自动生成图标、提示音并编译（需要 Windows 自带的 .NET Framework 编译器，无需安装任何 SDK）
